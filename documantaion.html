MailMate - Domain and Subscription Manager

MailMate helps developers, agencies, and businesses manage domains, hosting, SSL certificates, email services, SaaS tools, and other digital subscriptions. It tracks expiry dates and sends automated renewal reminders.

Features

Authentication

Registration, login, email verification, password reset, JWT sessions, bcrypt hashing, profiles, and admin/user roles.

Subscriptions

Manage domains and services with owner details, multiple emails, expiry dates, costs, currencies, notes, auto-renew, and notifications.

Custom Options

Use a custom subscription type such as VPN or Cloud Backup, and define a custom renewal period in months.

Dashboard

View active, expiring, and expired assets, upcoming renewals, charts, SSL warnings, and currency-separated cost totals.

Email System

Configure SMTP, send test messages, create HTML/text templates, and receive automated reminders with delivery logs.

Integrations

Use Gemini AI templates, WHOIS/RDAP lookup, SSL inspection, Slack/Discord webhooks, CSV import, and CSV export.

How the Application Works

  1. The user creates an account and verifies their email.
  2. The user logs in and adds a domain or subscription.
  3. The user enters the expiry date, cost, currency, owner email, and reminder intervals.
  4. The backend stores the record in MongoDB and calculates its status.
  5. A cron job runs daily at 8:00 AM UTC and checks matching reminder dates.
  6. Nodemailer sends the reminder through SMTP and the result is saved in Email Logs.
  7. Dashboard analytics display counts, upcoming expiries, cost projections, and separate currency totals.

Installation and Setup

Requirements

Node.js 18+, MongoDB or MongoDB Atlas, an SMTP account, and a Gemini API key.

Install

npm run install:all
npm run dev:backend
npm run dev:frontend

Environment Variables

backend/.env
MONGODB_URI
JWT_SECRET
JWT_EXPIRES_IN
PORT
FRONTEND_URL
NODE_ENV
SMTP_HOST, SMTP_PORT, SMTP_SECURE
SMTP_USER, SMTP_PASS
SMTP_FROM_NAME, SMTP_FROM_EMAIL
GEMINI_API_KEY

frontend/.env
VITE_API_URL=http://localhost:5000/api

Default URLs: http://localhost:5173 frontend, http://localhost:5000 backend, and /health for the server health check.

Presentation Demo Flow

  1. Register or log in.
  2. Show dashboard statistics and charts.
  3. Add a Domain, Hosting, SSL, or Custom subscription.
  4. For Custom type, enter a custom name such as VPN or Cloud Backup.
  5. For Custom renewal, enter the period in months.
  6. Show PKR and USD totals separately with subscription counts.
  7. Run domain/SSL lookup.
  8. Generate an AI email template.
  9. Configure SMTP and send a test email.
  10. Open Email Logs, dark mode, Privacy Policy, and Terms & Conditions.

Production Notes

  • Scope subscription and email-log queries to the authenticated user.
  • Protect admin-only operations with admin middleware.
  • Encrypt stored SMTP passwords.
  • Add rate limiting, security headers, strict CORS, backups, and monitoring.
  • Never commit real environment secrets.
